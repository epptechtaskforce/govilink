Install on iPhone or iPad
  1. Open this page in Safari.
  2. Tap the Share button (square with an arrow).
  3. Choose Add to Home Screen, then Add.
  4. Open GoviLink from your home screen.
Install it from your browser
  1. Chrome on a computer: click the install icon at the right end of the address bar, or open the menu (⋮) → Cast, save and share → Install page as app.
  2. Edge on a computer: menu (…) → Apps → Install this site as an app.
  3. Android: in Chrome tap the menu (⋮) → Install app.

Firefox and some other browsers cannot install apps; please use Chrome or Edge. If you removed GoviLink earlier, your browser may take a little while to offer the button above; the address-bar icon or menu always works.
